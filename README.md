# Работа с коллекциями в Python


## Содержимое репозитория

| Файл | Что делает |
|------|------------|
| `task1.py` | Сравнивает наличие товаров на складах в Москве и Казани с помощью множеств |
| `task2.py` | Считает статистику поисковых запросов (частота, доля самого популярного, уникальные запросы) |
| `task3.py` | Анализирует заказы: сумма возвратов, покупатели с возвратами, средний чек |
| `task4.py` | Считает выручку по дням недели, лучший день, выручку на заказ, дни с долей возвратов > 20% |
| `task5.py` | Агрегирует отзывы по товарам: средние оценки, худший товар, доля низких оценок |

## Требования

- Python 3.9+ без использования сторонних зависимостей

## Установка

```bash
git clone https://github.com/knight99rus/omd/
cd omd/homework_6
```

## Запуск

```bash
python task1.py
python task2.py
python task3.py
python task4.py
python task5.py
```
